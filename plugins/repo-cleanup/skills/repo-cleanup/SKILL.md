---
name: repo-cleanup
description: Review stale repository instructions and documentation when asked for cleanup. Trace a conflict or broken reference and preview the smallest correction.
---

Start at the entry point a reader or agent actually uses, such as the README, AGENTS.md or CLAUDE.md. Follow the relevant references to the file that owns the guidance. Check callers or backlinks before treating a file as unused. Establish what superseded an instruction using a current source, decision or observed behavior. Age alone is insufficient.

Show the entry point and owner (the authoritative file, plus a maintainer if known). Quote the conflicting wording or identify the dead link. Preview the smallest edit, any references it affects, and a check that would show a fresh reader or session reaches the right instruction. If ownership or intent is uncertain, say what would resolve it.

For a review, finish with the proposal. Apply only requested corrections. Preserve historical evidence and follow the project's archive convention when an approved move is needed.
