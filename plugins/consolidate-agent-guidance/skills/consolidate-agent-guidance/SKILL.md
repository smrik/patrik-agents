---
name: consolidate-agent-guidance
description: Weigh collected evidence and propose source-linked changes to an agent guide, or use that guide to recommend skills for a named project.
---

Read the evidence and guide named by the user. Defaults are `agent-guidance/SOURCES.md` and `agent-guidance/GUIDE.md` relative to the consuming project. Accept pasted evidence and guide text too. If the guide is new, propose its first supported entry. Identify any missing evidence needed for a decision.

For each material decision, compare sources by product, model, task and date. Distinguish documented behavior, local observations and preferences. Quote the existing wording and propose the shortest accurate replacement for that decision. Include a version detail or exception only if it changes the recommendation for this project. Link the source and explain why to adopt, keep, test or defer. For local evidence, link from the target guide to the relevant project file or section. Name any skill the change affects.

When asked to update the guide, apply supported edits in place and retain dated history in the evidence file. For a recommendation, leave the proposal in the reply.

For a project skill recommendation, use the maintained guide and the next deliverable. Inspect the applicable instruction files, project skill folders and the skills exposed in the session. Identify inherited or plugin skills where known and distinguish installed copies from available skills. Recommend the smallest selection, including zero. Give each proposed addition's trigger and any effects on other tasks. Installation is a separate action.
